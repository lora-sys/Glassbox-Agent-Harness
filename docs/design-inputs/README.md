# Design Inputs Archive

本目录为 Glassbox Web 管理后台设计输入的原始静态归档文件（Design Freeze v2，2026-09）：

1. `DESIGN.md`：原始产品定义、页面结构与数据语义契约。
2. `DESIGN_EVAL.md`：原始设计验收检查清单与测试场景。
3. `UI_PRIMITIVES.md`：原始组件约束与组装规范。
4. `glossbox_vercel_admin_v24_vercel_compliance.html`：可独立在浏览器中打开的完整交互原型与 Vercel 规范基准（v24）。

> **注意**：
> 仓库内已建立统一的 UI 设计文档入口：[`../ui-design.md`](../ui-design.md)。
> 所有设计原则、页面结构、UI primitives、视觉交互规范、评估结论、Vercel 合规要求及架构边界均已在 `ui-design.md` 中统一组织与澄清。日常开发与实现请以 `docs/ui-design.md` 为准，本目录仅作为不可变外部输入的追溯备份。
