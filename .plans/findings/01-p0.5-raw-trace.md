## Trace Format

Each Raw Trace is a JSONL file at `<repo>/.glassbox/sessions/<sessionId>/trace.jsonl`.
One JSON object per line, appended strictly in order of event arrival.

```json
{
  "seq": 1,
  "ts": "2026-08-28T20:30:00.000Z",
  "event": { "method": "thread/started", "params": { "thread": { ... } } },
  "provenance": "codex-app-server"
}
```

| Field | Type | Description |
|---|---|---|
| `seq` | integer | Monotonically increasing, starts at 1 per session. Computed from line count on append. |
| `ts` | string (ISO-8601) | Wall-clock timestamp of when the event hit the store. |
| `event` | object | `{ method: string, params: Record<string, unknown> }` — the raw method string and params from the JSON-RPC notification, collected by the adapter's optional `traceCollector` callback before any decoding or dispatch. |
| `provenance` | string | Always `"codex-app-server"` for this store. |

Example trace file (2 events, `turnStarted` then `turnCompleted`):

```
{"seq":1,"ts":"2026-08-28T20:30:00.001Z","event":{"method":"turn/started","params":{"threadId":"..."}},"provenance":"codex-app-server"}
{"seq":2,"ts":"2026-08-28T20:30:05.123Z","event":{"method":"turn/completed","params":{"threadId":"...","turn":{...}}},"provenance":"codex-app-server"}
```

**Append-only guarantee:** The store uses `appendFileSync(..., "utf-8")` which never truncates. Writing a second batch to the same `sessionId` adds lines to the end of the file, increasing `seq` continuingly. A restart of the process, a new `RawTraceStore()` instance, or even appending concurrently from multiple processes — each call computes `seq` from the current line count, so no event is ever lost or overwritten.

### Refresh safety detail

The "refresh safety" test:
1. Creates a session directory
2. Writes 2 events via ephemeral `new RawTraceStore()` instances
3. Loads the trace — confirms all 2 events are present in order with correct `seq`
4. Appends a 3rd event via yet another new instance
5. Loads again — confirms all 3 events are present

This proves that the trace file is durable across store instances and that append-only semantics hold across process restarts.

## Adapter Change

`apps/server/src/codex/adapter.ts`: `collectTurnEvents` now accepts an optional `traceCollector` callback. When provided, it receives `(method: string, params: Record<string, unknown>)` for every JSON-RPC notification before any dispatch logic runs. This is synchronous (no `await`) and non-blocking — it safely captures the raw event metadata for the trace without affecting the existing count/approval/delta collection logic.

## Security: Secret-Bearing Event Fields

**Status: PRESERVED VERBATIM — FLAG FOR P0 (screening before S4 Canvas surfacing)**

From the P0.3 spike findings the following Codex event types carry sensitive data into the trace:

| Event type | Fields | Risk class |
|---|---|---|
| `item/completed` (type: `commandExecution`) | `item.aggregatedOutput` | HIGH — may contain file paths, env vars, secrets from command stdout |
| `item/completed` (type: `commandExecution`) | `item.command` (the shell command itself) | MEDIUM — may expose API keys passed as CLI args |
| `item/fetchedUrlContent` | `content` (fetched page body) | MEDIUM — may contain tokens, credentials in body |
| `item/mcpToolCall/result` | `result` (tool return payload) | HIGH — arbitrary provider output, may include sensitive data |
| `item/agentMessage/delta` | `delta` (agent text) | MEDIUM — agent may quote file contents with credentials |
| `item/autoApprovalReview/*` | approval context snippets | MEDIUM — context sent to reviewer may include sensitive data |

**Recommendation for P0 follow-up:** The trace store currently preserves all fields verbatim. This is correct for the Raw Trace role (evidence), but before any Canvas surfacing happens in S4, implement a screening layer between the trace store and the Canvas projection that:
1. Redacts `aggregatedOutput` and `content` fields exceeding a configurable length threshold
2. Replaces known secret patterns (API keys, tokens, credentials) with `[REDACTED]`
3. Never redacts from the JSONL file itself — redaction should happen at the projection layer only, so Raw Trace remains uncorrupted evidence

The Raw Trace store should notAuto-redact. The screening belongs at the Canvas projection boundary, after the loader but before surfacing to the user.
