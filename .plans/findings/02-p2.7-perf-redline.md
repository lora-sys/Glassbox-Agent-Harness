# P2.7 — Performance redline measurement

## Method

Synthetic 2186-event / 12-turn session generated by `apps/server/src/scripts/gen-synthetic-trace.mjs`, written directly to `.glassbox/sessions/perf-redline-1788083532/trace.jsonl` (831.9 KB). The trace uses the exact `method/params` shapes understood by the reducer (`turn/started`, `item/started`, `item/agentMessage/delta`, `item/completed`, `item/fileChange`, `turn/diff/updated`, `turn/completed`, `action.send`). Verified replayable via `replayTrace()` → 2186 events, 12 turns, 264 artifacts.

Playwright (`apps/web/e2e/p27-perf.spec.mjs`), standalone `tsx` runner (not the Playwright test runner), headless Chromium, viewport 1400x900, 20 iterations after 1 warm-up.

Measurements:
- **Select (isolated):** `performance.now()` before/after `editor.select(shapeId)` inside `requestAnimationFrame` callback — captures JS execution to next frame commit (includes React render).
- **Select (+render):** `performance.now()` from `editor.select()` to `data-glassbox-inspector` textContent available, Node-side.
- **Inspector open:** time from post-select to inspector content length non-zero.
- **Pan:** `page.mouse.down → move(steps=4) → mouse.up`, 150px diagonal.
- **Zoom:** single `page.mouse.wheel(deltaY=-120)` frame, 30ms settle.
- **Initial render:** `performance.now()` from `page.goto()` to `editor.getCurrentPageShapes().length >= 5`.

## Machine context

- Linux 7.1.9-arch1-2, Arch Linux
- Node.js v24.20.0, Playwright Chromium (headless)
- Viewport: 1400x900
- 291 Canvas shapes produced from 2186 trace events

## Verdict

**PASS** — All six bars met with margin. Redline is recorded. No speculative optimization needed.

Key observations:
- Selection latency converges to ~50ms p50 after first frame (reconciliation steady state).
- Inspector content is available within 2ms of selection — it's already mounted, just reading cached data.
- Pan is the slowest interaction (p95=271ms) due to mouse steps (4 subtests) and mouse.move sequencing. Still under 500ms bar.
- Initial render at 1.2s leaves 3.8s margin before the 5s bar.
