# Task: P2.8b — The agent's final answer gets its own Canvas object (browser-verified)

Found during the owner's P2.8 acceptance run on the real repo nanobot (session 92b9b48d-6077-46c8-bc08-c44d7ca6deff in .glassbox/sessions/). The run produced a 3930-char final report (the last agentMessage delta). The Canvas shows only the first 180 chars of the CONCATENATED deltas — which is the first intermediate narration line — so the actual result is invisible on the Canvas. AGENTS.md: work and results belong on the Canvas. Read the trace of that session to see the real data before coding.

## Root cause
1. The claude adapter emits each assistant text block as one item/agentMessage/delta carrying the FULL message text (fine for capture). The reducer concatenates all deltas into turn.agentMessageText. buildBoardObjects renders that blob truncated to ~180 chars.
2. There is no "final answer" concept: nobody marks which message is the turn's result.

## Fix
1. apps/server/src/claude-code/adapter.ts: when the `result` event arrives (turn completing), emit a new trace event `item/agentMessage/final` { threadId, turnId, text: <the last assistant text block seen this turn>, completedAtMs }. Track the last assistant text block during the turn (you already iterate content blocks).
2. apps/server/src/state: reducer case agentMessageFinal -> store turn.finalAnswer = text (new field on TurnRecord). replay.ts METHOD_TO_TAG mapping. Schema entry for the new method.
3. apps/web buildBoardObjects: for each completed turn with a non-empty finalAnswer, render a dedicated **Answer** object: the FULL text (no truncation), width ~720, autoSize, placed in its own lane (for example a second column at x ~ 760, aligned with its turn's y, or below the turn stack — pick what reads best; keep the flow-layout pass from S9 so nothing overlaps). Style the label "Answer:" prefix like the other objects. Zooming out shows the whole report; zooming in reads it. That is the point.
4. Codex parity note: codex deltas are true incremental tokens; leave the codex path on the existing accumulated-text behavior and add a code comment that the final-answer event is claude-code-specific until codex exposes message boundaries.
5. Inspector: when turn.finalAnswer exists, render it at the top of the turn's Inspector section (before the delta list) as the primary content.
6. Tests: reducer test for agentMessageFinal (finalAnswer set, replay deterministic); adapter test emitting result after assistant messages produces the final event with the last text block (extend the fixture).
