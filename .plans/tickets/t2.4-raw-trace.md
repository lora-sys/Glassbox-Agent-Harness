# Task: S2 / T2.4 — Raw Trace store (apps/server)

T2.3 added Effect Schema decode: codex events now decode into typed CodexEvent values with typed Schema.ParseError failures. This ticket persists those events as Raw Trace so a run can be reopened and reconstructed without depending on Canvas layout.

## Glassbox rule
Raw Trace is evidence. It is append-only and never rewritten. Glassbox-derived state may be re-derived, but Raw Trace must not be edited to match the UI. Reconstructing what happened during a run must not depend on Canvas layout. (Notion: Runtime, Codex and Trace; Security model.)

## Goal
A RawTraceStore that appends every decoded codex event (plus a timestamp and provenance) to a per-session trace file, and a loader that reads it back. The /run-test endpoint should write a trace; a GET /trace/:sessionId endpoint should read it back.

## Steps
1. apps/server/src/trace/store.ts: a RawTraceStore class. Method append(sessionId, event: CodexEvent) writes one JSON line per event to <repo>/.glassbox/sessions/<sessionId>/trace.jsonl. Each line is JSON with: the decoded CodexEvent, a monotonic seq number, an ISO timestamp, and a provenance field (source: "codex-app-server"). Append-only: never overwrite or delete existing lines. If the file exists, append.
2. apps/server/src/trace/load.ts: a loadTrace(sessionId) function that reads <repo>/.glassbox/sessions/<sessionId>/trace.jsonl and returns the ordered list of trace entries. This is how a run is reconstructed. It must NOT read any Canvas layout file.
3. apps/server/src/index.ts: /run-test now generates a sessionId (uuid), runs the turn, appends every decoded event to the trace store, and returns the sessionId plus the event summary. Add GET /trace/:sessionId that returns the full ordered trace.
4. Add apps/server/src/trace/store.test.ts: run /run-test (or call the adapter + store directly), then loadTrace the same sessionId, and assert the reconstructed event sequence matches what /run-test produced. Also assert that restarting the store (new instance, same file) and loading still returns the same sequence (proves refresh does not destroy the trace).
5. Create the <repo>/.glassbox/sessions/ directory on first write. The .gitignore already ignores .glassbox/.

## Security

The trace store should preserve them verbatim for now (evidence), but flag this as a follow-up for P0 (screening before Canvas surfacing happens in S4).
- Never write to the user real ~/.glassbox/. Only write to <repo>/.glassbox/sessions/.

## Verify
- POST /run-test returns a sessionId. GET /trace/:sessionId returns the same event sequence.
- A second RawTraceStore instance loading the same sessionId returns the identical sequence (refresh-safe).
- The trace file is append-only: running /run-test twice with the same sessionId produces a file with both runs' events, neither overwriting the other.
