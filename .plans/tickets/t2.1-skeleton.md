## Goal
Build the monorepo skeleton plus an apps/server package that starts an empty HTTP server. No Codex adapter, no Effect decode, no real features yet. Just a home for them.

## Structure (from README and Notion)
- Root: workspace config, .gitignore, root package.json
- apps/server: Node + TypeScript runtime (HTTP, WebSocket, Codex adapter, event normalization). This ticket: empty shell only.
- packages/contracts: shared schemas, command and event types. This ticket: empty index.
- packages/shared: small runtime-independent utilities. This ticket: empty index.
- apps/web and packages/agent-runtime: NOT in this ticket (apps/web is S3; agent-runtime only if a later ticket needs it).

## Steps
1. Explore vp: run `vp --help` and `vp create --help` to see if vp supports a workspace or monorepo scaffold. If yes, use it. If no, set up a workspace manually (npm or pnpm workspaces with a root package.json workspaces field).
2. Create the root layout: root package.json (name glassbox, private true, workspaces ["apps/*","packages/*"]), pnpm-workspace.yaml or npm workspaces config, .gitignore (node_modules, dist, .glassbox/, .vite-plus/, *.tsbuildinfo, .DS_Store).
3. apps/server: package.json (name @glassbox/server, type module, scripts dev/start/build, deps effect@4.0.0-rc.112 plus typescript plus a TS runner such as tsx or vite-node). tsconfig.json. src/index.ts that starts an empty HTTP server on a port from env or a default. Use plain Node http for the empty shell (Effect adoption gate is a later ticket, just have effect installed as a dependency).
4. packages/contracts: package.json (name @glassbox/contracts, type module), tsconfig, src/index.ts with an empty export.
5. packages/shared: package.json (name @glassbox/shared, type module), tsconfig, src/index.ts with an empty export.
6. Run the workspace install (vp install or pnpm install or npm install) and confirm it succeeds.
7. Run apps/server dev or start and confirm the empty HTTP server responds on its port (a GET returns any response, even 404 or a health JSON).
8. Add a trivial import of @glassbox/contracts and @glassbox/shared from apps/server src/index.ts to prove the workspace links resolve. Then remove or keep the trivial import, your call, just prove it resolves.
9. Do not commit anything (leave git alone). Just create files.

## Verify
- Workspace install succeeds with no errors.
- apps/server starts and an HTTP GET to its port returns a response.
- @glassbox/contracts and @glassbox/shared resolve from apps/server.
